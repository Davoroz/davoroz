# David Orozco — academic website

Static site (HTML + CSS + a little JS) deployed with GitHub Pages.

- `index.html` About  ·  `research.html` Research  ·  `cv.html` CV
- `styles.css` all styling; colours and fonts live in `:root` at the top
- `assets/cv/David_Orozco_CV.pdf` the downloadable CV (replace to update)
- `.github/workflows/pages.yml` automatic deployment on push to `main`

To add a publication, copy the commented template in `research.html`.
